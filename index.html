Progression AMRAP
4 mouvements · Top set + 2 back-offs AMRAP RPE9 · +2.5kg (haut) / +5kg (bas) par semaine
📖 Rappel du protocole
Top set = poids de la semaine, AMRAP RPE9.
Back-off 1 = -5% du top set, AMRAP RPE9.
Back-off 2 = -10% du top set, AMRAP RPE9.

Cluster : si le top set tombe à ≤3 reps, passe ce mouvement en cluster (1 rep + pause 20-30s répétée). Tu peux aussi réduire les back-offs de 10% supplémentaires.

Fin de cycle : quand la majorité des mouvements sont en cluster et la fatigue s'accumule, lance un nouveau cycle (bouton ci-dessous, sur chaque mouvement) — retest le 1RM ou redémarre ~70% du niveau atteint.
